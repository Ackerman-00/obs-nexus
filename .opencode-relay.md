1. **`rpmbuild -bs` cannot be re-run inside this sandbox**: all 29 specs
   fail `-bs` with `Bad file: <payload>` because the payload artifacts are
   `.gitignore`d and exist only on OBS. This is an environment gap of the
   CI runner, not a spec error — the authoritative build evidence is the
   OBS build log/matrix (87/87 terminal) plus the locally rebuilt
   fleet-rotation RPMs.
2. **No `%check` in the prebuilt-payload packages.** They repack upstream
   binaries; there is nothing to build or test beyond
   `desktop-file-validate` (which several already run). Adding empty
   `%check` sections would only silence an rpmlint warning.

   the 20 specs it rewrites, 6 are pure line reordering and the other 14
   include a genuine regression — it turns the desktop field code `%U` into
   the undefined macro `%{U}` in concat, fluxer, heroic-games-launcher,
   obsidian and openchamber (and inserts `# FIXME` comments). Applying it
   would rebuild 20 packages and could corrupt the installed `Exec=` lines.

   window in these containers. The install + `ldd` + binary probe is the
   ceiling this pipeline can reach; Electron's

   not a package defect.

   44.10.2 line hermes ships is clean. Those runtimes are built and shipped
   by upstream inside their payloads, so the only fix is an upstream
   rebuild — recorded, not fabricated as fixed.
