## Workflow fix this run (IMPROVE THE MACHINE)

1. .github/workflows/update-packages.yml: the Smart Sync step's
   `collect_pkgs` dedupes internally, but the repo-vs-OBS
   drift-reconciliation loop APPENDS the same packages to PKGS_TO_SYNC
   without a membership check, so a package that was both committed this
   run AND drifted got `sync_files` called twice: every file uploaded to
   OBS twice and runservice/rebuild triggered twice. Evidence: run
   40085879446 shows 41 "Uploading X to OBS" lines for only 2 changed
   packages (concat-unstable + rootapp), generic debian.* files 4x each
   (2 pkgs x 2 passes). Harmless today (PUT idempotent, OBS dedupes
   builds) but doubles API traffic and would double-rebuild on any future
   non-idempotent step. Fixed: iterate
   `$(printf '%s\n' $PKGS_TO_SYNC | sort -u)` so each package syncs
   exactly once regardless of how many sources appended it. Committed
   3be6fdc, pushed, verified on remote (line 522). Validated:
   python yaml.safe_load OK, zero invalid permissions keys.
