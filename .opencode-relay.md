### Harness lessons (runner-side only, no repo change)

- `zypper install --no-gpg-checks` is NOT a valid flag on current zypper —
  for locally-built unsigned RPMs use `rpm -ivh --nodeps` then resolve runtime
  deps via `zypper install` of the named providers.

  `awk -F- '{print $1}'` (mangles `helium-browser` -> `helium`).

  repo's `noarch/` dir, NOT `x86_64/` — query the right index.
- GH Advisory API: `gh api advisories` 404s; use
  `api.github.com/advisories?ecosystem=rust&affects=<pkg>` with the token.
