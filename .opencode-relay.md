## The chrome-sandbox defect, with commands

`%exclude <path>` removes a path from the WHOLE file list, so a later
`%attr`/`%verify` line cannot re-add it, and the `%post` chmod was dead code
operating on a file that was never installed.

$ dpkg-deb -c koharu_0.85.6-1+4.1_amd64.deb | grep sandbox
-rwxr-xr-x root/root  14992 ./usr/share/koharu/chrome-sandbox        <- not setuid
